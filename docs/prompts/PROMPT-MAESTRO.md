# 3. VISIÓN DEL PRODUCTO

Desarrollar una plataforma que permita descubrir, analizar y monitorear información económica, financiera y empresarial que pueda representar oportunidades de inversión o negocios.

El sistema debe identificar acontecimientos importantes publicados en fuentes oficiales y otros canales autorizados, incluso cuando tengan poca cobertura mediática.

La plataforma debe responder:

- ¿Qué está ocurriendo en la economía?
- ¿Qué proyectos están recibiendo autorizaciones?
- ¿Qué empresas están realizando nuevas inversiones?
- ¿Qué licitaciones y contratos representan oportunidades?
- ¿Qué instrumentos financieros están disponibles?
- ¿Qué sectores pueden beneficiarse de determinados acontecimientos?
- ¿Qué oportunidades comerciales pueden derivarse de esos acontecimientos?
- ¿Qué riesgos y condiciones deben evaluarse antes de actuar?

La plataforma NO debe presentar especulaciones como hechos confirmados ni prometer rendimientos financieros.

# 4. MÓDULOS PRINCIPALES

## Módulo A — Radar de inteligencia económica

Desarrollar un sistema centralizado de acontecimientos económicos.

Funciones:

- Recopilar información de fuentes autorizadas.
- Clasificar noticias y documentos.
- Identificar acontecimientos relevantes.
- Detectar información duplicada.
- Conservar documentos originales y referencias.
- Registrar fechas de publicación, detección y actualización.
- Identificar organizaciones y sectores involucrados.
- Permitir búsqueda y filtrado.
- Generar alertas de acontecimientos relevantes.

Categorías iniciales:

- Energía.
- Construcción.
- Turismo.
- Industria.
- Infraestructura.
- Tecnología.
- Finanzas.
- Comercio.
- Agricultura.
- Transporte.
- Inversiones extranjeras.

## Módulo B — Permisos y proyectos

Monitorear fuentes oficiales que publiquen información accesible sobre:

- Permisos ambientales.
- Proyectos inmobiliarios.
- Autorizaciones energéticas.
- Proyectos turísticos.
- Infraestructura pública.
- Nuevas instalaciones industriales.
- Concesiones y autorizaciones regulatorias.

Cada proyecto debe tener una ficha con:

- Nombre.
- Empresa promotora.
- Ubicación.
- Sector.
- Descripción.
- Monto anunciado, si existe.
- Estado administrativo.
- Fecha de autorización.
- Institución responsable.
- Documento oficial.
- Historial de cambios.
- Posibles oportunidades comerciales.

Distinguir claramente entre proyecto propuesto, permiso solicitado, permiso aprobado, construcción iniciada y operación.

No inferir que un proyecto está aprobado simplemente porque aparece en un registro.

## Módulo C — Instrumentos financieros

Implementar seguimiento de:

- Instrumentos del Banco Central.
- Subastas y resultados publicados.
- Títulos del Ministerio de Hacienda.
- Emisiones del mercado de valores dominicano.
- Instrumentos de renta fija.
- Tasas de interés.
- Vencimientos.
- Rendimientos.
- Liquidez y riesgos.

Funciones:

- Comparador de instrumentos.
- Calculadora de rendimientos.
- Historial de tasas.
- Calendario de vencimientos.
- Alertas de nuevas emisiones.
- Información de requisitos de participación.
- Diferenciación entre tasas indicativas, adjudicadas y efectivas.

No presentar instrumentos como disponibles para compra sin confirmación.

## Módulo D — Licitaciones y contrataciones

Integrar datos públicos de contrataciones gubernamentales.

Funciones:

- Detectar nuevas licitaciones.
- Identificar fechas límite.
- Consultar presupuestos.
- Mostrar adjudicaciones.
- Identificar proveedores.
- Clasificar contratos por sector.
- Detectar oportunidades para pequeñas empresas.
- Analizar posibles oportunidades de subcontratación.
- Alertar sobre vencimientos.

Las oportunidades de subcontratación serán inferencias comerciales, no contratos garantizados.

## Módulo E — Expansión empresarial

Detectar:

- Nuevas fábricas.
- Aperturas de sucursales.
- Expansiones industriales.
- Inversiones extranjeras.
- Nuevos parques energéticos.
- Proyectos de infraestructura privada.
- Anuncios de contratación.
- Alianzas comerciales.
- Inversiones en maquinaria y tecnología.

Relacionar cada acontecimiento con empresas, sectores y necesidades comerciales potenciales.

## Módulo F — Motor de oportunidades

Este será uno de los principales diferenciadores.

A partir de acontecimientos verificados, generar oportunidades potenciales de:

- Inversión financiera.
- Prestación de servicios.
- Suministro de productos.
- Participación en licitaciones.
- Subcontratación.
- Creación de empresas.
- Expansión comercial.
- Consultoría técnica.
- Automatización.
- Eficiencia energética.
- Desarrollo tecnológico.

Ejemplo:

Un proyecto hotelero obtiene una autorización ambiental.

El sistema puede identificar necesidades potenciales de instalaciones eléctricas, climatización, seguridad, telecomunicaciones, automatización y mantenimiento.

Para cada oportunidad generar:

- Descripción.
- Hecho que la origina.
- Evidencia disponible.
- Sector beneficiado.
- Ubicación.
- Capital estimado, únicamente cuando exista una base justificable.
- Requisitos de participación.
- Riesgos.
- Horizonte temporal estimado.
- Nivel de confianza.
- Próximos pasos posibles.

Nunca inventar cifras, proveedores, contratos o rendimientos.

# 5. SISTEMA DE INTELIGENCIA ARTIFICIAL

Diseñar un sistema modular con funciones especializadas.

## Agente 1 — Discovery Agent

Responsabilidades:

- Detectar nuevas publicaciones.
- Revisar fuentes configuradas.
- Identificar cambios.
- Registrar metadatos.
- Enviar documentos al pipeline.

## Agente 2 — Extraction Agent

Responsabilidades:

- Extraer entidades.
- Detectar cantidades y monedas.
- Identificar fechas.
- Identificar proyectos y organizaciones.
- Extraer condiciones y restricciones.
- Conservar fragmentos de evidencia.

Utilizar extracción estructurada y validación de esquemas.

## Agente 3 — Verification Agent

Responsabilidades:

- Contrastar información.
- Comprobar documentos oficiales.
- Detectar contradicciones.
- Identificar información desactualizada.
- Diferenciar hechos de hipótesis.
- Evitar duplicados.
- Señalar contenido no verificable.

La ausencia de una segunda fuente no debe invalidar automáticamente un documento oficial auténtico.

## Agente 4 — Opportunity Intelligence Agent

Responsabilidades:

- Relacionar acontecimientos.
- Identificar sectores beneficiados.
- Detectar necesidades comerciales.
- Generar hipótesis de oportunidades.
- Evaluar relevancia económica.
- Explicar razonamientos.

No debe ejecutar inversiones ni emitir recomendaciones personalizadas sin las salvaguardas regulatorias correspondientes.

## Agente 5 — Financial Analysis Agent

Responsabilidades:

- Calcular rendimientos bajo supuestos explícitos.
- Comparar instrumentos.
- Analizar vencimientos.
- Identificar riesgos.
- Crear escenarios.
- Explicar sensibilidad a tasas, inflación y liquidez.

Los cálculos financieros deterministas deben realizarse mediante código verificable, no depender exclusivamente de respuestas generativas.

## Agente 6 — Alert Agent

Responsabilidades:

- Identificar acontecimientos importantes.
- Comparar con preferencias de usuarios.
- Evitar alertas duplicadas.
- Priorizar información.
- Generar notificaciones.
- Registrar entregas y errores.

## Reglas generales de IA

Todos los agentes deberán:

- Producir salidas estructuradas.
- Registrar modelo y versión utilizados.
- Conservar evidencia.
- Utilizar validación de esquemas.
- Controlar costos.
- Gestionar errores y reintentos.
- Respetar límites de APIs.
- Protegerse contra prompt injection.
- Evitar ejecutar instrucciones encontradas dentro de documentos externos.
- Permitir revisión humana.
- Medir precisión y errores.
- No inventar información faltante.

Diseñar un sistema de evaluación con conjuntos de prueba representativos antes de habilitar publicación automática.
